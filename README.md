# pwang724.github.io

Redirects only. Everything that used to be served at pwang724.github.io (wc3env, the fly notebook, Skeleton Tennis)
now lives on https://offpolicyinc.com, built from `offpolicyinc/offpolicysite`. GitHub serves `404.html` (and
`index.html`, a copy) for every address here, and it sends visitors to the new page. Project repos no longer use
GitHub Pages. To redirect another old project, add a line to `ROUTES` in `404.html` and copy it over `index.html`.

The old personal site that used this name is in `pwang724/old-personal-site`.
